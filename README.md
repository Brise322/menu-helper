# Menu Helper 出国点餐助手

**简体中文** | [English](README.en.md)

一段 prompt：把国外餐厅的菜单拍照发给 AI，它会翻译每道菜、说明是什么，你回编号，它给你一张当地语言的点菜卡片，拿给服务员看。

ChatGPT、Gemini、Claude、豆包，能看图的 AI 都能用。

## 为什么做这个

我在国外吃饭经常碰到这些情况：
- 菜单上的单词都认识，连起来不知道是什么菜。
- 用翻译软件翻完，中文对不上原文，没法指给服务员看。
- 不要葱、几分熟、结账怎么说，还得一句一句再查。

最后多半是指着一行说 "this one"。这个 prompt 把看菜单和点菜放在一次对话里做完。

## 用法

### 1. 发菜单照片

AI 先介绍这家店：什么菜系、怎么点、哪几道是当地招牌。然后按分类列出全部菜品：

```
📍 Ταβέρνα Ο Μανώλης · EUR · 5 类 · 17 项
🗺️ 希腊菜 · 克里特岛哈尼亚
希腊家常小酒馆，前菜、沙拉、主菜可以几个人分着吃。主菜 9.5–16 €，面包和餐位费按人另收。
🏅 必尝：#1 酸奶黄瓜酱、#3 达科斯、#7 慕萨卡、#11 焖烤羊肉

### 🍽️ 主菜 Κυρίως
| # | 菜名 | 原文 | 是什么 | 价格 |
| 7 | 🏅 慕萨卡 | Μουσακάς | 希腊版千层面：茄子+肉酱+白酱焗 | 11,00 € |
| 9 | 烤内脏卷 | Κοκορέτσι | ⚠️ 肠衣裹内脏串烤 | 12,00 € |
| 10 | 炭烤章鱼 | Χταπόδι στα κάρβουνα | | 16,00 € |
```

「是什么」一栏的写法：
- 薯条、可乐这类一看就懂的，空着。
- 没见过的菜，拿熟悉的东西打比方。
- 🏅 当地招牌。
- ⚠️ 内脏、生食、味道重、烈酒、大份。

### 2. 回编号

比如 `3 7 10x2 不要洋葱`。份量、几分熟、套餐选项这类必须选的，AI 会先问你。

### 3. 把手机给服务员

先是一张中文确认清单，带价格和折合人民币。下面是给服务员看的卡片：

```
━━━━━━━━━━━━━━━━
🙋 Θα θέλαμε να παραγγείλουμε τα εξής, παρακαλώ.
   We'd like to order these, please.

・Ντάκος ×1
・Μουσακάς ×1
・Χταπόδι στα κάρβουνα ×2
   Χωρίς κρεμμύδι, παρακαλώ.
━━━━━━━━━━━━━━━━
```

卡片下面是常用语：叫服务员、要水、不要辣、打包、结账、分开付、刷卡。日语、泰语、希腊语这类不用拉丁字母的，附罗马音。最后一行写当地给不给小费。

**过敏、忌口**：发照片时说一句，比如「我对花生过敏」「不吃猪肉」。可能含有的菜会标 🚫，卡片第一行用当地语言写明过敏，请厨房确认。

### 4. 吃到一半

| 你发 | 你会得到 |
|---|---|
| `再加 8` | 只列新加菜品的卡片 |
| `7 换成 9` | 一张「把 X 换成 Y」的卡片 |
| `账单多少` | 当前合计 |
| 小票照片 | 逐行翻译，和点过的菜对一遍 |
| 菜单下一页 | 编号接着往下排；换一家店从头开始 |

## 安装

**临时用**：复制 [`prompt.md`](prompt.md) 全文，在 ChatGPT、Gemini 或豆包里新开对话发出去，再发菜单照片。

**长期用**：
- **ChatGPT**：新建 GPT，把 `prompt.md` 粘进「说明」（不到 8000 字符）。
- **Gemini**：新建 Gem，同样粘贴。
- **Claude**：把 `SKILL.md` 和 `prompt.md` 放进 `menu-helper` 文件夹，压成 zip（zip 里第一层是 `menu-helper/`）。设置里打开 Code execution，在 Customize → Skills 上传。

## 用之前

- **思考强度选「中」或默认。** 开到最强，它会一直联网查，一份菜单要等好几分钟。
- **照片拍清楚。** 正对着拍，别反光。一页拍不下就分几张，价格那列也要拍进去。看不清的价格会显示 `?`。
- **有要求就加一句。** 比如「3 个人，人均 30 欧以内」「不吃辣」「想吃当地特色」，介绍和推荐会照这个来。

## 局限

- 菜单上没有的菜和价格不会编。看不清的写 `?`，并说明该补拍哪里。
- 不确定的菜会标「推测」。
- 🚫 只是提醒，过敏一定当面跟服务员确认。
- 税、服务费、餐位费（日本的お通し、意大利的 coperto）只有菜单上印了才会提。
- 折合人民币是估算。

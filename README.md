# Menu Helper 🍜 出国点餐助手

**简体中文** | [English](README.en.md)

> 看不懂的菜单，拍一下就能点。

## 为什么写这个

在国外吃饭，最尴尬的往往不是开口说话，而是拿到菜单的那一分钟。

看到一份不熟悉语言的菜单就头大，满眼生词，查了几个也拼不出这道菜到底是什么。

满页的菜名，每个词你可能都认识，连起来就不知道端上来的是什么。Bruschetta 是面包还是沙拉？ねぎま里有没有葱？这跟语言水平关系不大，雅思 8.5 也照样看不懂。说实话，就算是中文菜单，"夫妻肺片""蚂蚁上树"第一次见也得猜半天。

然后服务员站在旁边等，你只好指着一行字说 "this one"，上菜了才知道点的是什么。

就算先用 AI 把菜单翻译了，后面的点餐还是麻烦：翻译出来的中文对不上菜单上的原文，要指给服务员看哪一道、怎么说不要葱、几分熟、怎么结账，还得一句句再去问。

这个 prompt 是我根据自己在外面吃饭的经历写的。目标很简单：**拍一下菜单，看懂每道菜，报几个数字，把手机递给服务员，就点完了。**

适合留学生、出国旅行的人，也适合任何拿着菜单发懵的人。不用装 App，也不用注册。ChatGPT、Gemini、Claude、豆包，能看图的 AI 都能用。

## 如何使用

**① 拍菜单**

先告诉你这是一家什么店、这里一般怎么吃、哪几道是当地必尝，然后按分类列出所有菜：

```
📍 Ταβέρνα Ο Μανώλης · EUR · 5 类 · 17 项
🗺️ 希腊菜 · 克里特岛哈尼亚
这是一家希腊家常小酒馆，可以合点前菜、沙拉和主菜分享。主菜每份约 9.5–16 €，另收每人面包及餐位费。
🏅 必尝：#1 酸奶黄瓜酱、#3 达科斯、#7 慕萨卡、#11 焖烤羊肉

### 🍽️ 主菜 Κυρίως
| # | 菜名 | 原文 | 是什么 | 价格 |
| 7 | 🏅 慕萨卡 | Μουσακάς | 希腊版千层面：茄子+肉酱+白酱焗 | 11,00 € |
| 9 | 烤内脏卷 | Κοκορέτσι | ⚠️ 肠衣裹内脏串烤 | 12,00 € |
| 10 | 炭烤章鱼 | Χταπόδι στα κάρβουνα | | 16,00 € |
```

"是什么"这一栏只写你点菜时需要知道的：
- 一眼能看懂的菜（薯条、可乐、黄瓜沙拉）留空
- 没见过的菜，用你熟悉的东西类比
- 当地招牌菜标 🏅，说一句为什么有名
- 会踩雷的标 ⚠️：内脏、生食、气味重、烈酒、份量大

**② 回复编号**，比如 `3 7 10x2 不要洋葱`

如果有必须选的，比如份量、几分熟、套餐配什么、按公斤卖要多重，它会先问清楚，不会替你选。

**③ 把手机递给服务员**

先给你一张中文确认清单，带价格和大概的人民币金额。下面是给服务员看的卡片：

```
━━━━━━━━━━━━━━━━
🙋 Θα θέλαμε να παραγγείλουμε τα εξής, παρακαλώ.
   We'd like to order these, please.

・Ντάκος ×1
・Μουσακάς ×1
・Χταπόδι στα κάρβουνα ×2
   Χωρίς κρεμμύδι, παρακαλώ.
━━━━━━━━━━━━━━━━
```

卡片上只有当地语言，服务员一眼就懂。

**过敏或忌口**：发菜单时顺手说一句（"我对花生过敏""不吃猪肉"），菜单表里可能含有的菜会标 🚫，给服务员的卡片第一行会用当地语言写明过敏、请厨房确认食材。

再往下是常用语：叫服务员、要水、不要辣、过敏、打包、结账、分开付、刷卡。每句都有当地语言和英语，非拉丁字母的语言（日语、泰语、希腊语等）另附罗马音，最后一行说明当地给不给小费。

**④ 吃到一半**
- 加菜：`再加 8`，只出新加的那几道
- 改单：只出一张"把 X 换成 Y"的卡片，不会让服务员重新下一遍单
- 问花了多少：`账单多少`
- 拿到小票：拍一下，逐行翻译，和你点的菜对一遍
- 菜单有好几页：接着拍，编号往下接；换了一家店会自动清空重来

## 如何安装

**最简单**：复制 [`prompt.md`](prompt.md) 全文，粘贴到 ChatGPT、Gemini 或豆包的新对话里发出去，然后发菜单照片。

**长期用**：
- **ChatGPT**：新建一个 GPT，把 `prompt.md` 全文粘贴进"说明"（不到 8000 字符，正好在上限内）。
- **Gemini**：新建一个 Gem，同样粘贴。
- **Claude**：把 `SKILL.md` 和 `prompt.md` 放进一个叫 `menu-helper` 的文件夹，压缩成 zip（zip 里顶层是 `menu-helper/`）。在设置里打开 Code execution，然后在 Customize → Skills 上传。

## 用之前注意

- **思考强度选"中"或默认，别开最强**：开到最强它会反复联网查资料，一份菜单要等好几分钟，饿着肚子等不起。
- **照片尽量拍清楚**：正对菜单拍，别反光、别糊。一页拍不全就分几张拍，价格那一栏也要拍进去，看不清的地方它只能标 `?`。
- **有额外需求直接说**：发照片时顺手加一句就行，比如"我们 3 个人，人均 30 欧以内""不吃辣""想吃当地特色"，它会按你说的来介绍和推荐。

## 它会老实告诉你的事

- 菜单上没有的菜和价格不会编；看不清的价格写 `?`，并告诉你该补拍哪一块
- 拿不准是什么菜时会标「推测」
- 图标只是参考，**过敏一定要跟服务员当面确认**
- 税、服务费、餐位费（比如日本的お通し、意大利的 coperto）只在菜单上印了的时候提醒
- 人民币金额是约数
